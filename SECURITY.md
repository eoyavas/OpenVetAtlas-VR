# Security Policy / Güvenlik Politikası

## 🌐 English

### Supported Versions
**OpenVetAtlas VR (oVa)** is a standalone offline Virtual Reality educational application for Meta Quest headsets (Quest 3, Quest 3S, Quest 2). It does not collect, store, or transmit personal user data, credentials, or telemetry over the network.

| Version | Supported |
| :--- | :--- |
| `v0.2.x-beta` / `v1.0.x` (Latest) | :white_check_mark: Yes |
| `< v0.2.0` | :x: No |

### Reporting a Vulnerability or Issue
If you discover a security vulnerability, crash, or critical bug within the software architecture or build pipeline:
1. Please use GitHub's **[Private Vulnerability Reporting](https://github.com/eoyavas/OpenVetAtlas-VR/security/advisories/new)** feature under the **Security** tab, or open an issue on the repository.
2. Include steps to reproduce the issue, the Unity version (`6000.x`), and the target headset model (e.g., Meta Quest 3S).

## 🇹🇷 Türkçe

### Desteklenen Sürümler
**OpenVetAtlas VR (oVa)**, Meta Quest gözlükleri (Quest 3, Quest 3S, Quest 2) üzerinde çevrimdışı (*offline*) olarak çalışan bir sanal gerçeklik eğitim uygulamasıdır. Uygulama hiçbir kişisel veriyi, kullanıcı bilgisini veya ağ telemetrisini toplamaz ve dış sunuculara iletmez.

| Sürüm | Destek Durumu |
| :--- | :--- |
| `v0.2.x-beta` / `v1.0.x` (Güncel) | :white_check_mark: Destekleniyor |
| `< v0.2.0` | :x: Desteklenmiyor |

### Güvenlik Bildirimi ve Hata Raporlama
Yazılım mimarisinde veya derleme yapısında bir güvenlik açığı ya da kritik bir hata tespit ederseniz:
1. GitHub üzerindeki **Security** sekmesinde yer alan **[Private Vulnerability Reporting](https://github.com/eoyavas/OpenVetAtlas-VR/security/advisories/new)** bağlantısını kullanabilir veya depo üzerinde bir kayıt (*Issue*) açabilirsiniz.
2. Bildiriminizde hatanın nasıl tekrarlandığını, kullanılan Unity sürümünü (`6000.x`) ve gözlük modelini (örn. Meta Quest 3S) belirtmeniz incelenmesini hızlandıracaktır.
